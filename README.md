# Python Programming Challenges

A collection of solutions to programming challenges from various sources, implemented in Python.

## Repository Structure

The repository is organized by the source of the problems:

### [LeetCode 150](./lc150/)
Solutions for the "LeetCode 150" curated list, organized by algorithmic category:
- **Array & Hashing**: `lc150/array_hashing/`
- **Binary Search**: `lc150/binary_search/`
- **Linked List**: `lc150/linked_list/`
- **Stack**: `lc150/stack/`
- **Tree**: `lc150/tree/`
- **Two Pointers**: `lc150/two_pointers/`
- **Graph**: `lc150/graph/`
- **Backtracking**: `lc150/backtracking/`

### [Elements of Programming Interviews (EPI)](./epi/)
Solutions from the book "Elements of Programming Interviews", organized by chapter:
- **Chapter 4**: `epi/c4/`
- **Chapter 5**: `epi/c5/`

## Getting Started

### Prerequisites
- Python 3.x

### Running Solutions
Each solution is a standalone Python script. Most scripts include their own test cases within the `if __name__ == "__main__":` block.

To run a specific solution:
```bash
python <path_to_file>.py
```

Example:
```bash
python lc150/array_hashing/two_sum.py
```
